🧬 The four playbooks, in plain English

A · Pedro — NASDAQ scalper

Prior-session volume profile (POC/VAH/VAL). Fade back to value; chase expansion breakouts. Many small trades, tight stops. Strength: harvests micro-reversions. Weakness: pays the chop tax; tight stops get hunted in ranges.

B · Andrea — patient fader

Bollinger + RSI extremes only when ADX<20 (self-declared chop trader). Few trades, waits for stretches. Result: only active style that never breached 5% MDD on any series.

C · Imry — regime router

ADX/ATR regime classifier + absorption stand-aside (high volume + tiny body = don't trade). Mean-revert in ranges, follow in trends, flat in storms. Lesson: daily-bar proxies whipsaw — needs intraday book data.

D · Nafi — beginner

One tiny random trade every ~20 bars, then flat. Mostly does nothing, uses a personal stop. Lesson: loses slowly long-run but has the highest lucky-day spikes — the video's green day, quantified.

⚙️ How it works (60 seconds)

Data → signals → costs → prop envelope → walk-forward

Live Yahoo Finance (ES=F, NQ=F, SPY, QQQ; 5y daily + 60d×60m cache). Signals computed causally (shift-1, next-bar execution). Futures costs: $4 RT + 1 tick/side; ETF: 1bp/side. Prop: $100k, static floor $95k, firm-daily 5%, personal-daily 3%. Rolling walk-forward 70/30 ×5; WFE accept ≥0.50, excellent ≥0.70.

Why daily bars for an intraday video?

Daily bars test the mechanism (frequency tax, stop fragility, idle edge) across 1,255+ bars and multiple regimes with free public data. The 60m cache is staged for the session-open replication (pre-registered, not cherry-picked).

What would change my mind?

A pre-registered CPI-week intraday run where high-turnover scalping keeps WFE>0.50 net of 2–3-tick slippage. The harness already supports it — bring CME replay data and we'll publish the update.

❓ FAQ

Is this financial advice?

No. Research and education only. Backtests overfit; futures involve substantial risk of loss.

Why does buy-and-hold win on return but still "fail"?

It wins the 5y bull drift (+77% to +111%) but every path breaches the 5% static MDD (−24% to −35%). Prop firms grade survival, not drift capture.

Can I add my own strategy?

Yes — add a function returning a shifted (-1, 0, 1) Series in src/strategies.py, register it in run_all.py, rerun. Lookahead tests guard you.
